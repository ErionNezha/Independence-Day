# 🇮🇳 Independence-Day

Flamuri i Indisë me shirita të valëzuar (saffron, e bardhë, e gjelbër) dhe Ashoka Chakra me 24 rreze — tani si SVG i brendshëm, pa imazhe të jashtme.

## 🚀 Si ta hapësh

Hap `index.html`, kliko **Live Demo** — flamuri valëvitet me animim CSS.
